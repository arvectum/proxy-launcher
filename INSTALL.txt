============================================
Arvectum Proxy Launcher (Windows)
============================================

РЕКОМЕНДУЕМАЯ КЛИЕНТСКАЯ УСТАНОВКА
  1) В папке поставки должны лежать:
       * Arvectum Proxy Launcher.exe
       * install.bat
       * uninstall.bat
       * restore_network.bat
       * INSTALL.txt
  2) Двойной клик по install.bat.
     EXE будет скопирован в:
       %LOCALAPPDATA%\ArvectumProxyLauncher
     На рабочем столе появится ярлык.
  3) В открывшемся окне введите внешний прокси:
       IP/host, порт, логин, пароль
  4) Нажмите «Включить прокси», затем «Проверить».
  5) Только после успешной проверки при необходимости включите
     «Запускать прокси при входе в Windows».

ВАЖНО
  * Автозапуск НЕ включается установщиком до настройки upstream.
  * При включении приложение сохраняет исходные WinINET-настройки и
    HTTP_PROXY/HTTPS_PROXY/ALL_PROXY/NO_PROXY; при выключении восстанавливает их.
  * Пока proxy включён, приложение ставит временный recovery-autostart в HKCU Run.
    Он нужен для защиты после reboot/crash и удаляется при нормальном выключении.
  * Исключения no_proxy применяются в PAC и внутри локального HTTP/SOCKS proxy.
    Добавление/удаление исключений также синхронизирует активный NO_PROXY.
  * Логин/пароль upstream пока хранятся локально в proxy_settings.json открытым
    текстом. Для частной доверенной поставки это текущее ограничение.
  * Неподписанный EXE может вызвать SmartScreen/Unknown publisher.

АВАРИЙНОЕ ВОССТАНОВЛЕНИЕ
  * В приложении: «Восстановить сеть».
  * Либо запустите restore_network.bat из папки поставки.
  * Если recovery сообщает ошибку, НЕ удаляйте папку
      %LOCALAPPDATA%\ArvectumProxyLauncher
    и не удаляйте proxy_*_backup.json вручную. Повторите восстановление и
    сохраните proxy_core.log для диагностики.

УДАЛЕНИЕ
  * Запустите uninstall.bat.
  * Uninstaller сначала подтверждает успешное восстановление сети.
  * Если rollback не завершён, удаление отменяется и recovery-файлы сохраняются.

СБОРКА ИЗ ИСХОДНИКОВ
  build_exe.bat выполняет py_compile + 16 unit/smoke tests, затем собирает
  one-file EXE через PyInstaller.
  Итог:
    dist\Arvectum Proxy Launcher.exe
