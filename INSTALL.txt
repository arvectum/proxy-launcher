Arvectum Proxy Launcher 0.2.3 P0.2
====================================

WINDOWS PORTABLE INSTALLATION

1. Download a Windows artifact from GitHub Releases or GitHub Actions.
2. Unpack it into a separate folder and start the supplied launcher/install helper.
3. The launcher uses the canonical executable location:
     %USERPROFILE%\Documents\ArvectumProxyLauncher
4. Persistent configuration, logs, and recovery data are stored in:
     %LOCALAPPDATA%\Arvectum\ProxyLauncher

USAGE

1. Open the launcher and configure the upstream proxy.
2. Enable the proxy and confirm connectivity.
3. Enable autostart only after a successful check.

SAFETY AND RECOVERY

* Installation never enables autostart before an upstream is configured.
* Upstream passwords use current-user Windows DPAPI and are not stored in plaintext.
* Before changing WinINET and proxy environment settings, the launcher preserves the existing state and will retain recovery data if rollback is incomplete.
* Use the launcher’s recovery UI first. `restore_network.bat` is an emergency helper when the launcher is unavailable.
* Do not delete state or recovery files manually while proxy operation or recovery is in progress.

MACOS / LINUX

The repository retains macOS/Linux scripts for continued development, but the Windows 0.2.3 safety architecture has not been validated on those platforms. They are not production release instructions at this time.
