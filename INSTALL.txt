Arvectum Proxy Launcher 0.2.2
============================================

УСТАНОВКА
  1. Полностью распакуйте ZIP-архив в отдельную папку.
  2. Запустите install.bat.
  3. После установки используйте ярлык «Arvectum Proxy Launcher» на рабочем столе.

Приложение устанавливается в:
  %USERPROFILE%\Documents\ArvectumProxyLauncher

Постоянные настройки, журнал и данные аварийного восстановления хранятся в:
  %LOCALAPPDATA%\Arvectum\ProxyLauncher

ИСПОЛЬЗОВАНИЕ
  1. Откройте Launcher ярлыком на рабочем столе.
  2. В «Настройки прокси…» укажите внешний proxy, если он ещё не настроен.
  3. Нажмите «Включить прокси».
  4. Дождитесь активного состояния.
  5. Нажмите «Проверить соединение».

Только после успешной проверки при необходимости включите «Запускать прокси
при входе в Windows».

ВОССТАНОВЛЕНИЕ СЕТИ
  * Если Launcher показывает состояние восстановления или диагностики, следуйте
    кнопке, которую предлагает интерфейс.
  * Не удаляйте вручную recovery/state-файлы и не сбрасывайте Windows proxy
    вручную без диагностики.
  * При ошибке восстановления повторите действие в Launcher. Для диагностики
    сохраните proxy_core.log из %LOCALAPPDATA%\Arvectum\ProxyLauncher.
  * restore_network.bat — дополнительный recovery helper из распакованной
    папки поставки; запускайте его только если Launcher недоступен.

УДАЛЕНИЕ
  * Запустите uninstall.bat из установленной папки.
  * Uninstaller сначала восстанавливает сеть. Если это не удалось, удаление
    отменяется, а recovery-файлы сохраняются для повторной попытки.

ВАЖНО
  * Автозапуск не включается установкой до настройки upstream.
  * Пароль внешнего proxy хранится в Windows DPAPI, привязанном к текущему
    пользователю Windows; он не записывается в открытом виде.
  * Неподписанный EXE может вызвать SmartScreen/Unknown publisher.
