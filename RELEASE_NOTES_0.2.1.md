# Arvectum Proxy Launcher 0.2.1

- Safer proxy recovery and exact restoration of prior network settings.
- Upstream credentials are protected by Windows DPAPI for the current user.
- Refreshed, accessible Windows UI and recovery guidance.
- Windows installer candidate with version metadata and third-party notices.

Known limitations:

- WinHTTP is configured separately and is not changed by this application.
- This is an unsigned signing candidate; Authenticode signing is pending a
  separate final audit.
