Arvectum Proxy Launcher - portable 0.2.3 P0.1 hotfix

1. Extract the ZIP to any folder and run "Arvectum Proxy Launcher.exe".
2. The first run updates its permanent working copy in:
   %USERPROFILE%\Documents\ArvectumProxyLauncher
3. Settings, no_proxy, recovery files and logs remain in:
   %LOCALAPPDATA%\Arvectum\ProxyLauncher
4. If you enable Windows autostart, it uses only the permanent Documents copy.
   It never points to a ZIP extraction folder or to %TEMP%.
5. Do not remove the AppData Arvectum folder while proxy recovery is pending.

This P0.1 package intentionally contains only the portable executable and this
instruction. Full installer, signing and SmartScreen work are deferred.
